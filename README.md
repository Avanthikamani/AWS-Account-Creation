 # CREATE AN  ACCOUNT IN AWS SET UP A ROOT USER AND AN IAM USER 
  ## AIM
       To Create an Account in AWS Set up a Root user and an IAM user.
## PROBLEM STATEMENT
    AWS Identity and Access Management (IAM) is a service that allows administrators to securely manage access to AWS resources. This experiment demonstrates how to create a Root User, create IAM Users, assign permissions using IAM policies, and verify user access by signing in with different accounts.

## ALGORITHM

Step 1: Create an AWS account and sign in as the Root User.

Step 2: Open the IAM Console and create an IAM User.

Step 3: Assign the required permissions or add the IAM User to an IAM Group.

Step 4: Generate login credentials for the IAM User.

Step 5: Log in using the IAM User and verify the assigned permissions.

## COMMANDS
No command-line commands were used. The experiment was performed through the AWS Management Console.
